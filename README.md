# Ofis Koltuğu Sonsuz Dönüş Sayacı

Bu proje, insanlığın en büyük sorunlarından birini çözmek için yaratılmıştır: **Ofis koltuğunuzun kaç kere döndüğünü bilmemek.**

Artık o dönem bitti. Bu yazılım, koltuğunuzun her dönüşünü sayar, kaydeder ve size abartılı bir şekilde raporlar. Bilimsel araştırmalar (ki yok) gösteriyor ki, koltuk dönüş sayısını bilen insanlar %347 daha mutlu oluyor.

## Nasıl Çalışır?

```bash
python koltuk_donus.py
```

Sonsuza kadar döner. Ctrl+C ile kurtulabilirsiniz. Belki.

## Özellikler

- Sonsuz döngü (gerçek anlamda)
- Rastgele ofis esprileri
- Dönüş sayacı
- Hiçbir işe yaramama garantisi

## Uyarı

Bu yazılım ofis koltuğunuzu gerçekten döndürmez. Sadece döndüğünü varsayar. Hayal gücünüzü kullanın.
